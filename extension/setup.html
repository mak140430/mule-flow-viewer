Optional: the local helper

For running DataWeave scripts and MUnit test inputs, and for self-hosted servers (GitHub Enterprise, your own GitLab or Bitbucket), which it opens from your clones. Each step ticks itself off.

  1. Python 3.8+ and git

    The helper is a small Python program; git reads the history of your clones.

    brew install python git
    winget install Python.Python.3.12 Git.Git
    sudo apt install python3 git

    No Homebrew? python.org has an installer; git comes with xcode-select --install.

  2. Register the helper

    In the folder you unzipped (the one with extension and helper in it), run:

    python3 helper/install.py
    py helper\install.py

    For your user only, no admin rights. Moved the folder later? Run it again.

  3. DataWeave CLI

    The engine the helper runs scripts, MUnit test inputs and output comparisons with.

    brew install mulesoft/data-weave/dw

    Download it from github.com/mulesoft/data-weave-cli and put dw on your PATH, then run install.py again so the helper sees it.

  4. Where your clones are

    For other code hosts: the helper finds the page's repository among your clones. Leave it empty to search your home folder.
